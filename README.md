# ПЗ 3–4. Django: пользователи, модели и ORM

Учебный проект по дисциплине **«Структура программного обеспечения и базы данных»**.

В проекте выполнены практические задания №3 и №4: настроена авторизация пользователей, созданы модели Django и связи между ними, выполнены миграции, реализована работа с базой данных через Django ORM и настроена административная панель.

## Используемые технологии

* Python
* Django 5.2.17
* SQLite
* Django ORM
* HTML

## Установка и запуск

Клонировать репозиторий и перейти в папку проекта:

```bash
git clone https://github.com/Informatika25/PZ3-4-BD.git
cd PZ3-4-BD
```

Создать виртуальное окружение:

```bash
python -m venv venv
```

Активировать его в Windows:

```bash
venv\Scripts\activate
```

Установить Django:

```bash
pip install Django==5.2.17
```

Выполнить миграции:

```bash
python manage.py migrate
```

Создать администратора:

```bash
python manage.py createsuperuser
```

Запустить сервер:

```bash
python manage.py runserver
```

## Модели

В приложении `accounts` созданы следующие модели:

* **Department** — факультет;
* **Course** — учебный курс;
* **StudentProfile** — профиль студента.

Между моделями настроены связи:

* `Department → Course` — `ForeignKey`;
* `User → StudentProfile` — `OneToOneField`;
* `StudentProfile ↔ Course` — `ManyToManyField`.
